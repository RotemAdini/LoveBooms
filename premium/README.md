# פצצות אהבה · הקופסה

גרסה נפרדת של המשחק שב-`../index.html`. הקובץ המקורי לא משתנה, ולגרסה הזו יש שמירה נפרדת בדפדפן.

## הרצה מקומית

```bash
node premium/tools/serve.mjs
```

ואז לפתוח את `http://localhost:4173/premium/`.

## קבצים

| קובץ | מה יש בו |
|---|---|
| `index.html` | עותק של המשחק עם נקודות חיבור לשכבה החדשה |
| `premium.js` / `premium.css` | לחיצה ארוכה, חפיסות, צלילים, מצב שולחן, שוברים, קלפים אישיים, קוד פתיחה, פתיחת הקופסה, מתנה, הדפסה |
| `decks.js` | כל הקלפים לפי רמת חום, ושוברי הפרס. עורכים כאן טקסטים |
| `config.js` | מחיר, קישור לדף התשלום (`buyUrl`), מיקום ערכת ההדפסה |
| `codes.js` | טביעות SHA-256 של קודי הפתיחה (נוצר אוטומטית) |
| `private/codes.csv` | הקודים עצמם. לא עולה ל-git |
| `manifest.webmanifest`, `sw.js`, `icons/` | התקנה למסך הבית ועבודה בלי אינטרנט |

## קודי פתיחה

```bash
node premium/tools/make-codes.mjs 100
```

מוסיף 100 קודים ל-`private/codes.csv` ומעדכן את `codes.js`. אחרי כל הרצה צריך לפרסם מחדש את `codes.js`.

הבדיקה נעשית בדפדפן בלבד. אין שרת, ולכן אותו קוד עובד בכל מכשיר ואי אפשר לבטל קוד בודד. זו נעילה שמספיקה ללקוח רגיל, לא הגנה מפני מי שמחפש לעקוף.

## מה בטעימה ומה בקופסה המלאה

- טעימה: כל המשחק והתחושה, עם 38 קלפים ברמת "חמים".
- קופסה מלאה: 181 קלפים בשלוש רמות חום, שוברי פרס, קלפים אישיים, הדפסה.
